# Movies Website

A Django-powered movies library website UI. This project serves as a foundation for a scalable, user-friendly collection of movie titles with basic features for browsing and user management[attached_file:1].

## Features

- Movie list and detail views for browsing and exploring film information[web:4].
- Responsive and clean website UI built with Django and HTML templates[attached_file:1][web:4].
- Basic user authentication: register, login, and logout[web:4].
- User profiles: edit avatar, bio, and social links[web:4].
- Movie categorization by genres[web:4].
- Pagination for movie listings[web:4].
- Homepage displays recent and popular movies[web:4].
- Commenting system for logged-in users (optional enhancement)[web:4].
- Admin dashboard for managing movies and users[web:4].

## Prerequisites

- Python 3.8 or higher[web:9][web:13].
- pip (Python package manager)[web:16].
- Git (for cloning the repository)[web:4][web:11].
- (Recommended) Virtual environment tool: `venv` or `virtualenv`[web:4][web:11].
- (Optional) TheMovieDatabase (TMDB) API key for bulk movie import[web:4].
